# 这个站测什么

Rex-Analysis 收录面向科研智能体的评测基准（bench）。每个 bench 测一种科研能力，有自己的任务、榜单和评分规则。

题目来自真实研究：给出题面和数据，由模型或智能体独立完成，再按隐藏的评分材料打分。评分材料不在这个站上公开。

# 榜单怎么读

- 每个 bench 一张榜，分开排名。不同 bench 的分数不可横比，也不合成一个总分。
- 一张榜里可以有多个分组，例如「大模型」和「智能体」。大模型组在同一套流程下运行，只比模型本身；智能体组比的是整套系统。
- 名次由生成脚本按各 bench 的规则算好，网页不重新排名。
- 一次提交没有覆盖全部题目时，照实写覆盖的题数，不把缺的题算成 0 分。

# 如何参与

- 选一个 bench，先读它的说明页。
- 下载公开任务包，让你的模型或智能体独立完成全部任务。
- 用官方评测流程打分，把完整运行目录发给我们，核对后上榜。

任务包和评测代码的地址，在各 bench 自己的页面上。
