# What this site measures

Rex-Analysis collects benchmarks for research agents. Each bench measures one research capability and has its own tasks, leaderboard and scoring rules.

Tasks come from real research: a statement and data are given, a model or agent completes the work independently, and hidden scoring material decides the result. That material is not published on this site.

# Reading a leaderboard

- One board per bench, ranked separately. Scores are not comparable across benches and are never combined into a single total.
- A board can have several groups, for example models and agents. The model group runs in one shared pipeline and compares the models themselves; the agent group compares whole systems.
- Ranks are computed by the build scripts under each bench's rules; the page never re-ranks.
- When a submission does not cover every task, the number of covered tasks is shown as is; missing tasks are not counted as zero.

# Getting involved

- Pick a bench and read its notes page first.
- Get the public task packages and have your model or agent complete every task independently.
- Score with the official pipeline and send us the full run directory; the entry goes on the board once checked.

Task packages and evaluation code are linked from each bench's own pages.
